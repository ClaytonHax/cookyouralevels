# Cook Your A Levels — Feature Roadmap

Goal: Help Cambridge CIE A Level students (Maths, Physics, CS) revise smarter using topical past paper questions, solutions, and AI-powered tools.

---

## Phase 1: Foundation ✅ (current)
- [x] Landing page with Google Sign In
- [x] Firebase Auth (Google only)
- [x] Dashboard layout with subject cards
- [x] Subject routing (Mathematics, Physics, Computer Science 9618)
- [x] AS Level & A Level separation
- [ ] Topic browser per subject
- [ ] Past paper questions viewer (topical)
- [ ] Mark scheme / solution viewer

## Phase 2: Content & Practice
- [ ] Question bank — Mathematics (Pure 1, Pure 2, Mechanics, Statistics, Further)
- [ ] Question bank — Physics (all AS & A Level topics)
- [ ] Question bank — Computer Science 9618 (Paper 1, 2, 3, 4)
- [ ] PDF viewer for original past paper images
- [ ] Question filtering by topic, year, paper number, difficulty
- [ ] Mark scheme side-by-side viewer
- [ ] Progress tracking per topic (% attempted, % correct)
- [ ] Bookmarking questions for later review
- [ ] Timed practice mode (mock exam simulation)

## Phase 3: AI Features
- [ ] AI paper marking — upload photo of handwritten answer, get feedback
- [ ] AI question generation — custom practice questions for any topic
- [ ] Weak topic identification — automatically surfaces struggling areas
- [ ] Personalised daily study plan based on exam date + performance
- [ ] AI step-by-step explanations for any solution

## Phase 4: Social & Gamification
- [ ] Friend system — compare progress with classmates
- [ ] Leaderboard (weekly / all-time per subject)
- [ ] Daily streak tracking
- [ ] Notes and annotations on questions
- [ ] More subjects: Chemistry, Biology, Economics, Further Maths
- [ ] Mobile app (React Native)
